# LocalChat — 局域网即时通讯系统

> **版本 1.5.0（正式版）** — 从 1.4.1-beta 转正发布，历经 1.0alpha → 1.5 六轮迭代与三轮安全审查。

基于 Node.js 的局域网即时通讯系统，支持 **网页版**、**完整命令行版** 与 **命令行便携版** 三种客户端，满足桌面、终端与移动端的多种使用习惯。

---

## ✨ 功能总览

### 用户系统
- 注册/登录：创建账号、ID 登录、昵称查找登录、本机已有账号一键登录
- 多账号管理：同一设备可注册多个账号（按 IP 关联）
- 修改昵称（长度限制 20 字符）

### 好友系统
- 搜索用户（昵称/IP，通配符按字面匹配）
- 发送/接受好友请求、查看待处理请求
- 删除好友、拉黑/取消拉黑（拉黑后对方无法再给你发消息）
- 实时在线状态（●/○ 指示）

### 实时聊天
- WebSocket 实时推送，私聊 + 群聊
- 消息撤回（发送后 2 分钟内）
- 文件发送：图片/音视频/文本（md/txt），在线预览与下载，上限 100MB
- 断线自动重连（3 秒），重连后自动补偿错过的消息
- 多端安全：同一账号重复登录时，旧连接收到明确提示并停止重连（无互踢风暴）

### 群聊
- 创建群聊、添加/移除成员（仅管理员）、群公告（仅创建者，上限 500 字符）
- 管理员转让（仅限群成员）、删除群聊（仅创建者）
- 群聊免打扰、@提及（ASCII 昵称）

### 三种客户端
| 客户端 | 说明 |
|---|---|
| **网页版** | 浏览器访问 `http://<IP>:3000`，功能最全，响应式暗色主题，localStorage 缓存 |
| **完整命令行版** | `npm run localchat`，全屏 TUI（terminal-kit），键盘导航，全部功能 |
| **命令行便携版** | `npm run portable`，仅好友对话与添加好友，轻量快速 |

## 📦 快速开始

### 服务器（任选一台电脑，需 Node.js 22+）

```bash
cd 1.5
npm install        # 首次需要
npm start          # 监听 3000 端口，启动后自动显示局域网 IP
```

同局域网设备通过 `http://<服务器IP>:3000` 访问网页版。

### 命令行客户端（同一台或局域网内任意电脑）

```bash
npm run localchat                # 完整版（连接 127.0.0.1:3000）
npm run localchat -- --server 192.168.1.100   # 指定服务器
npm run portable                 # 便携版
```

> 提示：命令行客户端只会在**连接成功**后记住服务器地址，错误的 `--server/--port` 不会污染后续启动；登录界面会显示当前服务器地址，便于排查连接问题。

## 🛡️ 安全与健壮性（1.4 系列修复汇总）

1.4 → 1.5 期间共修复 **20 项**问题：

| 类别 | 修复内容 |
|---|---|
| 服务器稳定性 | WS 消息处理全面 try/catch + 业务校验，畸形/恶意输入不再导致进程崩溃 |
| 权限 | 群消息需成员资格、群管理需管理员、历史消息仅对话双方、文件访问限相关方、转让管理员限群成员 |
| 安全 | 群成员列表 XSS 转义、/cli 页面 host 头转义、搜索 LIKE 通配符转义、用户名/群名/公告长度限制 |
| 多端 | 重复登录踢旧连接（带 kicked 通知，无互踢循环）、断线重连消息补偿 |
| 客户端健壮性 | 服务器不可达不崩溃、超长昵称/极窄终端不崩溃、登录界面 WS 事件不串扰、Ctrl+C 全界面可退出 |
| 体验 | 服务器业务错误三端可见提示、连接失败不污染配置、日志 7 天轮转 |

### 数据与隐私
- 数据库 SQLite（WAL 模式），数据存放于 `data/` 目录（已在 .gitignore 中排除）
- 上传文件白名单扩展名校验，存储使用随机文件名
- 局域网信任模型：**无登录密码，ID 即身份**（适合家庭/办公室可信网络）

## 🏗️ 项目结构

```
1.5/
├── public/                  # 网页前端（HTML/CSS/JS，无框架）
├── cli/                     # 完整命令行客户端（terminal-kit TUI）
├── portable/                # 命令行便携版（仅好友对话）
├── server/                  # 后端
│   ├── index.js             # Express + WebSocket 入口
│   ├── db.js                # SQLite 初始化 + 迁移
│   ├── websocket.js         # WS 消息处理（含踢连接/心跳）
│   ├── logger.js            # 日志（7 天轮转）
│   ├── models/              # 数据模型（user/friend/group/message/block/file）
│   └── routes/              # REST API 路由
├── data/                    # SQLite 数据库 + 上传文件（运行时生成）
└── package.json
```

## ⚙️ 技术栈

| 层 | 技术 |
|---|---|
| 运行时 | Node.js 22+（内置 node:sqlite） |
| HTTP 服务 | Express 4 |
| 实时通信 | ws（WebSocket） |
| 数据库 | SQLite（node:sqlite，WAL，免第三方依赖） |
| 网页前端 | 纯 HTML/CSS/JS |
| 命令行前端 | terminal-kit |
