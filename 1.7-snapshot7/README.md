# LocalChat — 局域网即时通讯系统

> **版本 1.6.1（正式版）** — 历经 1.0alpha → 1.6.1 九轮迭代与五轮全面审查，修复 40+ 项问题。

基于 Node.js 的局域网即时通讯系统，支持 **网页版**、**完整命令行版（键盘导航）** 与 **命令行便携版** 三种客户端。

---

## ✨ 核心特性

### 账号体系（IP-序号）
- 账号身份清晰直观：**`IP-N`**（如 `192.168.43.4-2` = 本机第 2 个账号），三端统一显示
- 同一设备可注册多个账号；"本机已有账号"一键登录
- IPv6 连接自动规范化，账号归属一致

### 网页版
- 注册/登录、好友系统（搜索/请求/拉黑/删除）、实时私聊/群聊
- **多行消息**（Shift+Enter 换行）、消息撤回（2 分钟）、@提及
- **文件发送与预览**：图片/音视频内嵌预览，**md/txt 在线渲染**（含 Markdown 语法），大文件自动转下载提示
- 群聊管理：创建/成员管理/公告/免打扰/转让/删除（权限分级）
- 在线状态实时显示、在线主机列表、localStorage 缓存（**按账号隔离**）
- 断线 3 秒自动重连并补偿错过的消息；多端登录互踢保护

### 命令行完整版（键盘导航优先）
- **默认选择模式**：`←→` 切换好友/群聊标签 → `Enter` 确认 → `↑↓` 选择 → `Enter` 进入聊天
- `Ctrl+E` 切换命令模式（26 个斜杠命令全部保留），`Esc` 逐级返回
- **好友请求快速处理**：顶部横幅提示"📩 收到 N 条好友请求"，按 `R` 进入详情视图，`↑↓` 选择、`Y` 接受、`N` 拒绝、`Esc` 返回——无需输入命令
- **局域网服务器自动扫描**（2 秒扫完 /24 子网）与手动修改地址
- 连接失败明确提示 + 恢复路径；服务器地址仅连接成功才记忆
- 好友请求状态栏徽标（📩）、离线请求登录即提示

### 命令行便携版
- 轻量：仅好友对话与添加好友，行式交互，适合快速使用

## 📦 快速开始

```bash
cd 1.6.1
npm install        # 首次
npm start          # 服务器（监听 3000，自动显示局域网 IP）
```

| 客户端 | 使用方式 |
|---|---|
| 网页版 | 浏览器打开 `http://<服务器IP>:3000` |
| 完整命令行 | `npm run localchat`（或 `--server IP:端口` 连其他机器） |
| 便携版 | `npm run portable` |
| CLI 安装指引 | `http://<服务器IP>:3000/cli` |

> 局域网内其他电脑：只需 Node.js + 复制 `1.6.1` 目录，运行 `npm run localchat -- --server <服务器IP>:3000`。

## 🛡️ 安全与健壮性（40+ 项修复汇总）

### 服务器
- WS 消息处理全面 try/catch + 业务校验（畸形输入不崩溃）
- 权限：群消息需成员资格、群管理需管理员、历史消息限对话双方、文件访问限相关方、转让限群成员
- 拉黑拒绝、重复撤回等业务错误三端可见提示
- 好友请求可**接受或拒绝**（拒绝实时通知请求方）
- 心跳超时清理、同账号重复登录踢旧连接（kicked 通知，无互踢循环）

### 多账号与隐私
- **消息缓存按账号隔离**（`chat_cache_<uid>_...`），同浏览器多账号互不可见
- 登出全面重置界面状态（输入框/标签/缓存/对话），无跨账号残留
- 删除好友实时通知对方

### 客户端健壮性
- 服务器不可达不崩溃（明确提示 + 扫描/改地址恢复路径）
- 超长昵称/极窄终端/多行消息不破坏界面
- 消息时间显示本机本地时间（非 UTC）
- 断线重连消息补偿、登录界面缩放自动重绘、菜单项防溢出

### 数据
- SQLite WAL 模式，数据存放 `data/`（git 已排除）
- 上传白名单扩展名 + 随机文件名 + 100MB 上限 + 失败自动清理
- 用户名/群名/公告长度限制；XSS 全路径转义；SQL 全参数化

## 🏗️ 项目结构

```
1.6.1/
├── public/          # 网页前端（HTML/CSS/JS，无框架）
├── cli/             # 完整命令行（terminal-kit TUI，含 scan.js 局域网扫描）
├── portable/        # 便携版（仅好友对话）
├── server/          # Express + WebSocket + SQLite
│   ├── models/      # user/friend/group/message/block/file
│   └── routes/      # REST API（含 /cli 安装指引页）
├── data/            # 数据库 + 上传文件（运行时生成）
└── package.json
```

## ⚙️ 技术栈

Node.js 22+（内置 node:sqlite，免第三方数据库依赖）· Express 4 · ws · terminal-kit · 纯原生前端
